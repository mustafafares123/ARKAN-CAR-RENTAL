# ARKAN CO. – RENT A CAR | Web starter

هذه نسخة أولية عملية قابلة للتشغيل محلياً، ومهيأة للانتقال إلى استضافة مؤقتة. الواجهة متجاوبة للكمبيوتر والهاتف وتدعم العربية والإنجليزية.

## ما الذي يعمل الآن؟
- لوحة تحكم ومؤشرات أسطول.
- أقسام السيارات والعملاء والحجوزات والعقود والصندوق والصيانة وأجهزة GPS والمخالفات.
- إضافة سجلات والبحث فيها.
- حفظ تجريبي داخل المتصفح الحالي (`localStorage`).
- تبديل العربية/الإنجليزية.
- تصميم قابل للتثبيت كتطبيق ويب على الهاتف (PWA manifest).

## تنبيه مهم
الوضع الافتراضي **تجريبي محلي**: البيانات تبقى في المتصفح والجهاز نفسه فقط، ولا تتزامن بين الموظفين أو الأجهزة. لا تدخل بيانات هويات أو جوازات أو عقود حقيقية قبل تفعيل قاعدة بيانات خاصة وتسجيل الدخول والصلاحيات. شاشة GPS لا تتصل بجهاز فعلي بعد؛ يلزم مزود GPS يدعم API ومفاتيح ربط محفوظة على الخادم. المخالفات الرسمية لا تُجلب تلقائياً إلا بوجود تكامل رسمي مع الجهة المختصة.

## 1) المتطلبات
- كمبيوتر Windows / macOS.
- تثبيت Node.js إصدار 20 أو أحدث من https://nodejs.org
- تثبيت VS Code اختياري.
- اتصال إنترنت لتنزيل الحزم.

## 2) تشغيل البرنامج على الكمبيوتر
1. فك ضغط `ARKAN_WEB_STARTER.zip`.
2. افتح المجلد `arkan-web-app` في VS Code.
3. افتح Terminal داخل المجلد.
4. نفّذ:

```bash
npm install
npm run dev
```

5. افتح هذا العنوان في Chrome أو Edge:

```text
http://localhost:3000
```

لإيقافه اضغط `Ctrl + C` في نافذة Terminal.

## 3) رفعه كرابط مؤقت على الإنترنت
1. أنشئ حساباً في GitHub: https://github.com
2. أنشئ مستودعاً جديداً خاصاً باسم `arkan-rent-a-car` (Private).
3. ارفع محتويات هذا المجلد إلى المستودع.
4. أنشئ حساباً في Vercel: https://vercel.com
5. اختر **Add New → Project** ثم اربط مستودع GitHub.
6. اترك إعدادات Next.js الافتراضية واضغط **Deploy**.
7. ستحصل على رابط مؤقت شبيه بـ `https://arkan-rent-a-car.vercel.app`.

الرابط الفعلي يتحدد بعد النشر، ولا يمكنني إنشاء حسابات GitHub/Vercel أو النشر نيابة عنك دون تسجيل دخولك وموافقتك.

## 4) قاعدة البيانات السحابية (الخطوة التالية قبل التشغيل الحقيقي)
1. أنشئ مشروعاً خاصاً في https://supabase.com
2. افتح SQL Editor وشغّل محتوى `supabase/schema.sql`.
3. من Project Settings → API انسخ Project URL و anon/public key.
4. أنشئ ملف `.env.local` في جذر المشروع بناءً على `.env.example`.
5. أضف القيم:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

6. أعد تشغيل التطبيق. ملاحظة: هذه النسخة تحتوي مخطط قاعدة البيانات كبداية، لكن ربط المصادقة ومزامنة جميع الشاشات يحتاج استكمال المرحلة التالية؛ مجرد وضع المفاتيح لا ينقل البيانات التجريبية إلى السحابة.

## 5) بيانات الشركة والأمان
- استخدم حسابات منفصلة للموظفين، ولا تشارك كلمة مرور واحدة.
- خزّن صور الهويات والعقود في Storage خاص (Private bucket) مع روابط مؤقتة.
- لا تضع `service_role` key في `.env` الذي يبدأ بـ `NEXT_PUBLIC_` أو في كود المتصفح.
- فعّل نسخاً احتياطية واختبر استعادة البيانات.
- أنشئ أدواراً وصلاحيات قبل إدخال بيانات العملاء.
- احتفظ بسجل تدقيق للتعديلات المالية والعقود.

## 6) مراحل التطوير المقترحة
1. ربط تسجيل الدخول وقاعدة البيانات فعلياً مع صلاحيات الفروع.
2. استيراد بيانات Excel والتحقق من التكرارات.
3. تطوير العقود PDF والتوقيع ومحاضر التسليم والاستلام.
4. دفتر الصندوق والعملات وأسعار الصرف والتقارير المحاسبية.
5. ربط مزود GPS عبر API بعد اختيار الجهاز والمزود.
6. تكامل المخالفات الرسمية إن وفرت الجهة المختصة واجهة رسمية.

## 7) الملفات المهمة
- `app/page.tsx`: الواجهة والمنطق الأولي.
- `app/globals.css`: التصميم المتجاوب.
- `supabase/schema.sql`: مخطط قاعدة البيانات وسياسات أولية.
- `.env.example`: أسماء إعدادات الربط المطلوبة.
