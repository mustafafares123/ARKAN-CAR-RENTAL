ARKAN CO. – RENT A CAR
ابدأ من هنا

1) فك ضغط الملف.
2) ثبّت Node.js 20 أو أحدث: https://nodejs.org
3) افتح مجلد arkan-web-app في VS Code.
4) افتح Terminal واكتب:
   npm install
   npm run dev
5) افتح Chrome واكتب:
   http://localhost:3000

للنشر المؤقت:
- اتبع قسم (3) في README.md باستخدام GitHub وVercel.
- ستحصل على رابط مؤقت بعد نجاح Deploy.

مهم:
هذه نسخة تطوير أولية. الحفظ الحالي محلي على نفس المتصفح.
لا تدخل بيانات عملاء حقيقية أو وثائق حساسة قبل ربط قاعدة بيانات خاصة وتفعيل تسجيل الدخول والصلاحيات.
